# v3.27 頁面載入記憶體回收修正版

修正 v3.26 閱讀數頁後出現「頁面載入錯誤」並重建章節的問題。章節排版快取仍保存在 SD 卡；載入要顯示的頁面前，若可用 RAM 少於 24 KiB 或最大連續區塊少於 16 KiB，先釋放可重建的字型點陣快取。記憶體充足時保留預熱成果。若實際載入仍遇到記憶體不足，釋放剩餘快取後重試同一頁。

持續低記憶體時最多排程三次重試，之後顯示記憶體不足提示，等待使用者下一次操作；不刪除章節索引、不回章首重建，也不把失敗頁面寫成新的閱讀進度。真正無法讀取／格式錯誤的快取沿用原有有限重建流程。

保留 v3.26 缺卡休眠時鐘、v3.25 跨章配置失敗保護、繁體中文、直排、注音、本章百分比、配對與閱讀設定。解壓後將 update.bin、diag.on 放到 SD 根目錄，依原方式更新，確認 v3.27。請使用原本那本書正常連續翻過先前出錯的頁面，確認沒有頁面載入錯誤或同章反覆索引；也請確認前後翻頁、跨章與 BLE 是否正常。尚待 X3 實機驗證，未量測翻頁速度與耗電差異。

# v3.26 休眠圖片缺失時顯示時間

休眠入口即時檢查 SD 卡；未掛載或已拔出時，改用內建字型顯示進入休眠當下的時間。自訂圖片找不到或沒有可用 BMP 時也改顯示時間。有卡且圖片可用時保留原桌布流程。進入休眠前卡已不存在時直接深睡，避免淺睡眠逾時檢查卡片後重啟並停留在缺卡訊息。不需要改掉自訂桌布設定；再次插卡並正常開機後照原設定使用。

時間沿用時區與 12／24 小時格式，尚未校時或 RTC 不可信時顯示 --:--。這是休眠當下的快照，不會在休眠中每分鐘刷新。時區與格式在正常休眠時備份到內部儲存，讓之後無卡開機再休眠仍能沿用；第一次使用新版前若從未有卡休眠，無卡開機僅有原始預設時區。此變更針對休眠畫面，開機時缺卡的提示仍保留。

保留 v3.25 跨章記憶體修正及所有配對、閱讀、待機降頻設定。解壓後將 update.bin、diag.on 放到 SD 根目錄依原方式更新，確認 v3.26。更新後先有卡正常休眠一次，再測試拔卡後進入休眠；也可測試圖片不存在、正常圖片、重新插卡開機。尚待 X3 實機確認。

# v3.25 跨章索引記憶體修正版（實驗版）

針對 v3.24 跨章索引時 ParsedTextVertical.cpp 逐字輸出容器配置失敗的崩潰：完整索引前釋放上一頁保留的字型點陣快取；沿用 ActivityManager 的 BLE 停止完成檢查。直排暫存批次由 800 詞縮為 192 詞，unit 門檻由 1000 調為 256（在詞邊界截批）。輸出容器先計算真正逐字筆數再預留，避免依 unit 數預留後再次成長。

僅直排排版的編譯單元啟用例外處理，配置失敗會先解構暫存容器，再標記 OOM、清除本次輸入並讓解析器中止建置。TextBlock arena 失敗也中止，不再跳過該欄繼續提交；沿用橫排 4 KiB 連續區塊地板。Section 既有的錯誤流程保留安全 partial，失敗內容不會標成完整章節。前景顯示記憶體不足提示，不以 crash 或固定重開機當成正常換章。

保留 v3.24 同章完整索引後連線、80 MHz 待機降頻、配對、按鍵設定、繁體中文、直排、注音與無前綴本章百分比。沒有更動 BLE 間隔或降低 BLE 記憶體門檻。

將 update.bin、diag.on 放到 SD 根目錄依原方式更新，確認 v3.25。請正常連續閱讀幾個尚未索引的章節；首次進章仍可能等待索引並暫停 BLE。重點確認能否完成索引並恢復連線；若出現記憶體不足或再次重開，保留 diag.log、diag-prev.log、crash_report.txt。桌面與編譯驗證不能取代 X3 實機驗證，尚未量測省電幅度。

# v3.24 藍牙連續閱讀與待機降頻實驗版

選定藍牙遙控器且啟用藍牙時，沒有完整快取的章節先完成本章索引，再啟動藍牙；已有完整快取直接使用。目的是避免只排幾頁便啟動藍牙，之後反覆重排與重連。原有部分快取會在讀取時完成重建；大章第一次進入可能等待較久。變更字型或排版設定仍需重新索引。未啟用藍牙或未選定遙控器時沿用原有漸進排版。
穩定連線、無掃描或連線作業且閒置超過 3 秒後，可降到 80 MHz（不套用 X3 一般的 10 MHz）；按鍵、掃描／重連或繪製鎖定時恢復正常速度。保留既有連線間隔與記憶體門檻，不加入自動淺睡眠。這版沒有實測電流與省電比例。
